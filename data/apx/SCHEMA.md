# F6 gear data schema (data/apx, read by src/apx/parts_data.cpp)

All files: JSON, ASCII, UTF-8 without BOM, keys sorted, no comments (use a "_note" string). Ids are
case-sensitive strings. Append rows; never reorder `affixes.json` (affix ids are file order). The loader
rejects: duplicate ids, unknown references, a material count over 255, an affix pool under 4 entries.
Validate offline: `build-tests\Release\parts_test.exe data\apx tests\apx\itemtypes.txt` (gate `data_load`).

## materials.json  `{"materials": [row, ...]}`
| key | type | meaning |
|---|---|---|
| id | string | unique, lower case (stone, iron, oak ...) |
| name | string | display name |
| density | int | kg/m^3 (real value); part mass = slot volume x density |
| hardness | int 0-10 | |
| tier | int 1-10 | depth gate: a part may use it when tier <= 2 + depth/3; Item Power factor |
| value_per_kg | int | gold per kg (trade, D73) |
| melt_c | int | melting point in C, 0 = does not melt |
| flammable | int 0-3 | |
| element | int 0-7 | 0 none 1 fire 2 frost 3 earth 4 storm 5 arcane 6 life 7 death (resonance) |
| salvage | "metal" / "magic" / "none" | station stand-in class (salvage.json stand_in) |
Rule: "flesh" never rolls on weapons or armour.

## forms.json  `{"families": [...], "slots": [...]}`
slots row: `{"id": "Blade", "role": "strike"|"structural"|"balance"|"grip"|"other", "volume": cm^3}`
(role weights for Item Power: strike 4, structural 3, balance 2, grip 1, other 1).
families row: `{"id": "Blades", "required": ["Blade", "Grip"], "optional": [{"slot": "Guard", "q": 2}, ...]}`
An optional slot appears when item quality >= q. A family must exist named "Plain" (fallback, one
required "Body"). At most 12 parts per item (APX_MAX_PARTS).

## form_map.json  (GENERATED by tools/apx/gen_forms.py from src/items.hpp; edit the rules there)
`{"IRON_SWORD": {"family": "Blades", "materials": ["iron", "wood", "hide"]}, ...}` - every Barony
ItemType name. materials[0] is the main material (strike/structural parts), the last is used for grip.

## affixes.json  `{"pools": [{"id": "Blade", "affixes": [{"name": "edge keeping", "pct": 10}, ...]}, ...]}`
Pool lookup per part: "<family>/<slot>", then "<slot>", then "*". A part rolls rarity-index affixes
(0-4) from its pool, distinct.

## salvage.json  (object)
looted_return_pct, crafted_return_pct, discharge_pct, aura_per_affix_pct, low_integrity_byte (0-255),
low_integrity_factor_pct, aura_item (Barony ItemType name), stand_in: [{"class", "item", "grams"}].

## recipes.json  (crafting slice, F6-C; see the crafting section of tools/apx/F6-PLAN.md)
`{"recipes": [{"family": "Blades", "slots": {"Blade": {"grams": 2400, "materials": ["iron", "steel", "bronze"]}, ...},
"bench": "forge"|"workbench"|"loom"|"any", "form_needed": 1}]}` - grams of material per slot; a
crafted item's parts take the materials the player supplies; form_needed = Formbook successes required.
